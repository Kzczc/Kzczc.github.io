## About

This is my personal academic homepage built with:

- **Next.js 16** + TypeScript
- **Tailwind CSS v4**
- **Framer Motion** for animations
- **Libre Baskerville** + **Fira Code** fonts

## Features

- 🎨 Terminal-style Recent Updates with live clock
- 📄 Selected Publications with paper thumbnails
- ⏳ Interactive Journey timeline
- 🏆 Awards & Honors with category tags
- 🌙 Dark / Light mode toggle
- 📱 Fully responsive design
- 🎤 Kiso & Sui mascot characters

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view.

## Deploy

Deployed on [Vercel](https://vercel.com). Every push to `main` triggers auto-deployment.
